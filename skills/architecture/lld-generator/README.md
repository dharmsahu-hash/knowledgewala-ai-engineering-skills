# lld-generator

Implementable low-level design (classes, sequences, schema, API, transactions) from an approved HLD.

- Template: `templates/lld.md`; checklists: `references/lld-checklists.md`
- Test scenarios: `tests/test-cases.md`
- Status: structurally validated. Real-world quality evaluation: not yet performed.
