## Detailed description

Designs and runs evaluation for LLM applications - prompt tests, agent workflow evaluation, RAG evaluation, regression suites, hallucination tests, output validation, model comparison, and cost and latency measurement, reporting only measured results. Use when an LLM feature needs a test plan, when a prompt or model change needs regression checking, or when comparing models.

Turn 'it seems to work' into measured, repeatable evidence for LLM features, and keep regressions out when prompts or models change.
