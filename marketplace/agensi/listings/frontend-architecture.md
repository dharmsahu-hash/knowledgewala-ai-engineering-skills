## Detailed description

Designs framework-neutral frontend architecture - component architecture, reusable design systems, responsive layout, accessibility, state management, API integration, error handling, performance, security and testing. Use when planning a new UI codebase, standardising components, or reviewing a frontend for structure, accessibility and resilience.

Give frontends a structure that scales across teams: clear component boundaries, one design system, predictable state and resilient data access.
