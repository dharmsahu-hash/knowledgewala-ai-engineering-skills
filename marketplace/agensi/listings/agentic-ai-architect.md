## Detailed description

Designs agentic AI applications - agent architecture, tool integration and function calling, multi-agent orchestration, memory and context engineering, RAG integration, guardrails, evaluation and observability, with framework guidance for LangChain and LangGraph where verified. Use when planning or reviewing an LLM-powered agent or multi-agent system, defining tool permissions, or adding safety limits and evaluation.

Design agent systems that are bounded, observable, safe with tools, and evaluated, rather than open-ended loops that happen to work in a demo.
