## Detailed description

Assesses application security against the OWASP Top 10 - authentication, authorisation, input validation, injection, secrets management, data exposure, dependency vulnerabilities, secure configuration and API security - separating confirmed vulnerabilities from potential risks. Use when reviewing code or design for security, before release of anything handling auth, payments or personal data, or after a dependency advisory.

Find and prioritise real security weaknesses with evidence, and give fixes, without exploiting systems or overstating risk.
