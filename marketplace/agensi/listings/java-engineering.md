## Detailed description

Writes, reviews and optimises modern Java (17, 21 and later LTS) - collections, streams, concurrency, exception handling, immutability, design patterns, clean code, JVM and garbage-collection tuning - with evidence-based performance advice. Use when implementing or refactoring Java code, diagnosing concurrency or memory problems, or choosing Java language and JVM features.

Produce correct, readable, maintainable Java that fits the project's existing conventions and Java version, and give performance advice that is measured rather than guessed.
