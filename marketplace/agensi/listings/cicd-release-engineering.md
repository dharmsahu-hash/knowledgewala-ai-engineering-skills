## Detailed description

Designs build, test and release pipelines - automated testing, artifact management, containerisation, deployment strategies, rollback plans, environment configuration, release validation and infrastructure as code - with approval gates before production. Use when creating or reviewing a CI/CD pipeline, planning a release or rollback, or hardening how software reaches production.

Make releases repeatable, tested, reversible and approved, without automatic production changes.
