## Detailed description

Diagnoses and improves application performance from measurements - CPU, memory, database and query efficiency, API latency, throughput, concurrency, caching and resource utilisation - with baseline, change and re-measurement for every claim. Use when an endpoint or job is slow, capacity is in question, or a performance requirement must be verified.

Make systems faster by finding the actual bottleneck and proving each improvement, instead of optimising by intuition.
