## Detailed description

Reviews code changes for correctness, maintainability, readability, performance, security, error handling, test coverage and architectural consistency, reporting only evidenced findings with severity, file and line, explanation, impact and remediation. Use when a diff, pull request or module needs an independent review before merge, or when a release gate requires a review verdict.

Give an independent, evidence-based merge verdict. The reviewer never invents defects and never claims verification it did not perform.

## Limitations

- A review reduces risk; it does not certify code as production-ready.
