## Detailed description

Produces a Low-Level Design from an approved HLD - class and sequence diagrams, database schema, API specifications, interface definitions, design patterns, error-handling strategy, transaction boundaries and concurrency considerations. Use when an HLD is approved and engineers need implementable detail before coding starts.

Turn an approved HLD into component-level detail precise enough to implement and test without further design decisions.
