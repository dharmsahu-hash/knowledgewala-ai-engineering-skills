## Detailed description

Designs and reviews REST APIs and integrations - resource modelling, OpenAPI specifications, versioning, authentication and authorisation, rate limiting, idempotency, pagination, error contracts and backward compatibility. Use when defining a new API, changing a published one, or reviewing an API contract for consistency, safety and performance.

Produce API contracts that are consistent, safe to evolve and easy to consume, before any implementation starts.
