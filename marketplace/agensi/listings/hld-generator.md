## Detailed description

Produces a High-Level Design from approved requirements and architecture decisions - system architecture, major components, data flow, integration points, API boundaries, infrastructure, security architecture and scalability strategy. Use when architecture is decided and a reviewable system-level design document is needed before low-level design or implementation planning.

Produce the system-level design that engineers, security and operations can review before detailed design starts.
